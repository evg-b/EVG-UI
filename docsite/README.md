# Документация EVG-UI

Сайт использует Docusaurus 3.10.2 и MDX 3.1.1. Это локальная часть репозитория
`evg-ui`: зависимости, scripts и lock-файл находятся в корне. Все команды ниже
нужно выполнять из корня репозитория.

## Установка и запуск

```sh
yarn install
yarn docs:dev
```

Команда сначала собирает библиотеку в `dist`, затем запускает документацию.
Импорты `@evg-b/evg-ui` направлены в локальный `dist/index.js`.
Для пересборки библиотеки при изменениях запусти `yarn watch` во втором терминале.

`CodeExample` и `PropDoc` находятся в `docsite/src/components`;
тот же `CodeExample` используется в стенде `playground`.

## Генерация документации props

```sh
yarn propdoc
```

Команда последовательно запускает три этапа:

- `yarn propdoc:jsonAPI` — извлекает типы и описания props в `docsite/Example/ApiDoc/APIs.json`.
- `yarn propdoc:APImdx` — создаёт страницы `docsite/docs/API` и список `docsite/APIdocs.ts`.
- `yarn propdoc:snippet` — обновляет исходники примеров для `CodeExample`.

Генератор props читает публичные компоненты из `src/index.ts` через
`react-docgen-typescript` и настройки корневого `tsconfig.json`. Типы из соседних
`.types.ts`, пересечения, `Omit` и наследование props разрешаются через TypeScript.
В JSON используются имена публичных экспортов, например `Button` и `ThemeProvider`.
Список API-страниц строится из этого JSON без отдельного списка разрешённых компонентов.

Описания записываются обычными комментариями `//` над свойством:

```ts
export type ExampleProps = {
  // Размер компонента.
  size?: 'small' | 'medium' | 'large'
}
```

Значения по умолчанию извлекаются из деструктуризации параметров компонента.
Также учитываются параметры локальных helpers, вызванных с `props` или `this.props`
первым аргументом, как `getCubesOptions(this.props)`. Ссылки на константы раскрываются
до их инициализаторов. Выражения сохраняются как текст исходного кода и не выполняются.
Неявные значения из внутренней логики компонента не вычисляются.

Свойства, унаследованные из React/HTML и других внешних зависимостей, исключены;
локально объявленные и переопределённые props сохраняются. Формат JSON соответствует
существующему `PropDoc`. При ошибке извлечения публичного компонента генерация
останавливается до перезаписи JSON.

Для генератора и ESLint используется совместимый JS API TypeScript 6 через alias
`typescript`; команда `yarn typecheck` по-прежнему запускает компилятор TypeScript 7.
Генерация запускается отдельно от сборки сайта. Скрипты находятся в `scripts/*.mts`
и запускаются через `tsx`; генератор примеров читает `.tsx` и записывает
`Examples.tsx` и `snippets.ts`. Старый Go-запуск перенаправлен на эту же команду.

## Сборка и просмотр

```sh
yarn docs:build
yarn docs:preview
```

Результат находится в `docsite/build`. Команда `yarn docs:clear` удаляет кеши
сборки документации.

## Публикация

```sh
GIT_USER=<Your GitHub username> USE_SSH=true yarn docs:deploy
```

Команда собирает библиотеку и публикует сайт в ветку `gh-pages`.
Core, classic preset и Babel-пресет Docusaurus закреплены на версии 3.10.2,
которая поддерживает React 19. Babel подключается через `@docusaurus/babel/preset`.
Конфигурация сайта находится в `docusaurus.config.ts`, меню — в `sidebars.ts`,
статическая конфигурация Babel — в `babel.config.json`.
Главная страница документации задаётся через `slug: /` в `docs/Installation.mdx`.

Старые примеры с JSS API `withStyles` ещё требуют переноса на текущий API `evg-ui`.

`AppBar` размещает заголовок экрана между навигацией и действиями. Передайте заголовок в `title`. Для панели внутри страницы задайте `position="static"`.

## Цвет {#color}

[Цветовые роли](../Styles/Color.mdx#props-color) можно передавать в `color`, например `primary`.

<AppBarColorExample />

## Действия слева и справа {#leftright-components}

`left` и `right` принимают React-элементы, например `IconButton` для навигации и `Button` для действия.

## Заголовок по центру {#titelcenter}

Передайте `titleCenter`, чтобы выровнять заголовок по центру панели.

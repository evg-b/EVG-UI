## Действия {#actions}

Положение действия задаёт `position` компонента `ListItemAction`.

```tsx
<ListItem button={false}>
  <ListItemAction position="start">
    <Icon name="Favorite" />
  </ListItemAction>
  <ListItemText>Избранное</ListItemText>
</ListItem>
```

<ListActionsExample />

## Дополнительные сведения {#meta}

В `meta` можно вывести время, а в `secondaryMeta` — счётчик рядом со второй строкой.

```tsx
<ListItemText
  meta="12:35"
  secondaryText="Новое сообщение"
  secondaryMeta={<Badge ripe count={2} />}>
  Анна
</ListItemText>
```

`Avatar` показывает изображение профиля из `src`. В `alt` передайте имя пользователя.

## Изображение профиля {#base-avatar}

<AvatarBaseExample />

## Пока изображение недоступно {#avatar-not-image}

До загрузки отображаются первые символы `alt`. По умолчанию виден один символ, количество задаёт `altMax`. Для пустого имени есть встроенная иконка.

<AvatarNotImageExample />

## Цвет {#color}

Для фона аватара можно выбрать одну из ролей темы. [Цветовые роли](../Styles/Color.mdx#props-color).

<AvatarColorExample />

## Размер {#size}

`size` задаёт диаметр в пикселях.

<AvatarSizeExample />

## Индикатор статуса {#status}

`status` добавляет индикатор рядом с изображением.

<AvatarStatusExample />

## Цвет индикатора {#statuscolor}

`statusColor` принимает цвет или роль темы.

<AvatarStatusColorExample />

## Несколько изображений {#multiple-avatar}

Передайте в `srcs` массив адресов, чтобы объединить изображения в одном аватаре.

<AvatarMultipleExample />

## Группа аватаров {#avatargroup}

`AvatarGroup` объединяет несколько компонентов `Avatar`. Количество видимых аватаров задаёт `max`.

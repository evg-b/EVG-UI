`Modal` выводит содержимое поверх приложения. Храните видимость окна в состоянии React, передавайте её в `open` и закрывайте окно в `onClose`.

## Клавиша Escape {#esc}

По умолчанию Escape вызывает `onClose`. Чтобы отключить закрытие с клавиатуры по Escape, передайте `isEsc={false}`.

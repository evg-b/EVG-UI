`Menu` открывает список рядом с элементом, на который указывает `target`. Каждый пункт — отдельный `MenuItem`.

## Выбор пункта {#base-menu}

Откройте «Сортировка» и выберите порядок. Пример хранит выбранное значение в состоянии React и закрывает меню через `open`.

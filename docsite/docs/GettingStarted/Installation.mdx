## Попробовать в репозитории

Из корня EVG-UI установите зависимости и запустите документацию. Проект использует Yarn Classic, а `nvm install` выбирает версию Node.js из `.nvmrc`.

```sh
nvm install
yarn install
yarn docs:dev
```

Откройте [Quick start](/docs/GettingStarted/quick_start), чтобы попробовать кнопки и переключение темы. Для отдельного стенда с компонентами есть команда `yarn dev`.

## Подключить к своему приложению

В npm версия `@evg-b/evg-ui@0.0.2` использует React 16 и JSS. Чтобы подключить компоненты и тему из этой документации, соберите пакет из текущего репозитория.

```sh
yarn build
yarn pack --filename evg-ui.tgz
```

В каталоге приложения установите архив и peer-зависимости. В примере клон EVG-UI лежит рядом с каталогом приложения.

```sh
npm install ../EVG-UI/evg-ui.tgz react@19.3.1 react-dom@19.3.1 styled-components@6.6.0
```

Архив содержит JavaScript из `dist`. Типы компонентов доступны в исходниках репозитория. Для проверки типов в отдельном приложении пакету пока не хватает деклараций `.d.ts`.

## Тема и иконки

Компоненты, иконки и `ThemeProvider` импортируются из `@evg-b/evg-ui`. По умолчанию провайдер включает светлую тему.

```tsx
import { Button, Icon, ThemeProvider } from '@evg-b/evg-ui'

export default function App() {
  return (
    <ThemeProvider>
      <Button variant="contained" color="primary" startIcon={<Icon name="Check" />}>
        Сохранить
      </Button>
    </ThemeProvider>
  )
}
```

Шрифт по умолчанию — `Roboto, Helvetica, Arial, sans-serif`. Чтобы задать свой стек, передайте `fontFamily` в `createTheme`. Настройка цветов и шрифта показана в [разделе Theme](../Styles/Theme.mdx), выбор иконки по имени — в [разделе Icon](../Components/Icon.mdx).

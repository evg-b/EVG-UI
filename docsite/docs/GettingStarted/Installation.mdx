Установите EVG-UI в проекте с React и React DOM версии 19.3.1.

<Tabs>
<TabItem value="npm" label="npm" default>

```sh
npm install @evg-b/evg-ui
```

</TabItem>
<TabItem value="yarn" label="Yarn">

```sh
yarn add @evg-b/evg-ui
```

</TabItem>
</Tabs>

Для EVG-UI нужны React и React DOM версии 19.3.1. В папке приложения установите библиотеку и styled-components.

<Tabs>
<TabItem value="npm" label="npm" default>

```sh
npm install @evg-b/evg-ui styled-components@6.6.0
```

</TabItem>
<TabItem value="yarn" label="Yarn">

```sh
yarn add @evg-b/evg-ui styled-components@6.6.0
```

</TabItem>
</Tabs>

Дальше [подключите EVG-UI к приложению](/docs/GettingStarted/quick_start).

Чтобы попробовать EVG-UI без установки, откройте [пример с кнопками и переключением темы](/docs/GettingStarted/quick_start).

## Соберите пакет

В npm пока опубликована предыдущая версия. Чтобы установить версию со styled-components, склонируйте EVG-UI рядом с папкой вашего приложения и соберите архив.

```sh
git clone https://github.com/evg-b/EVG-UI.git
cd EVG-UI
yarn
yarn build
yarn pack --filename evg-ui.tgz
```

## Добавьте EVG-UI в приложение

Откройте терминал в папке приложения и установите архив вместе с React и styled-components.

```sh
yarn add file:../EVG-UI/evg-ui.tgz react@19.3.1 react-dom@19.3.1 styled-components@6.6.0
```

Типы для TypeScript пока доступны только в исходниках EVG-UI.

Теперь можно [добавить первую кнопку](/docs/GettingStarted/quick_start#first-button).

## Первая кнопка в приложении {#first-button}

После [установки EVG-UI](./Installation.mdx) вставьте пример в `src/App.tsx`. `ThemeProvider` задаёт светлую тему, а кнопка считает нажатия.

```tsx title="src/App.tsx"
import { useState } from 'react'

import { Button, ThemeProvider } from '@evg-b/evg-ui'

export default function App() {
  const [count, setCount] = useState(0)

  return (
    <ThemeProvider>
      <Button
        type="button"
        variant="contained"
        color="primary"
        onClick={() => setCount((value) => value + 1)}>
        Нажатий — {count}
      </Button>
    </ThemeProvider>
  )
}
```

В проекте на Vite запустите `yarn dev` и откройте адрес из терминала. Нажмите кнопку — число нажатий увеличится.

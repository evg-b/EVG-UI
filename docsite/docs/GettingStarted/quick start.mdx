После [установки EVG-UI](./Installation.mdx) создайте в приложении два файла — `App.tsx` и `App.styled.ts`. В первом находятся кнопки и состояние React, во втором — оформление карточки.

## Кнопки и тема

Нажмите «Добавить», затем переключите тему. Карточка и кнопки поменяют цвета, а значение счётчика сохранится. Откройте «Показать код» и выберите нужный файл.

<AppExample />

`generateTokens({ primaryColor })` создаёт светлый и тёмный наборы токенов. `createTheme` собирает из каждого набора тему, а `ThemeProvider` передаёт выбранную тему и кнопкам EVG-UI, и карточке из `styled-components`. Фон карточки берётся из `theme.surface`, цвет текста — из `theme.onSurface`.

## Запуск в приложении

В шаблоне Vite для React и TypeScript замените `src/App.tsx`, положите рядом `App.styled.ts` и запустите dev-сервер командой `npm run dev`. Если вы подключаете React к пустой странице, добавьте `<div id="root"></div>` в HTML и отрисуйте приложение в точке входа.

```tsx title="main.tsx"
import { createRoot } from 'react-dom/client'

import App from './App'

const root = document.getElementById('root')
if (root) createRoot(root).render(<App />)
```

Чтобы изменить цвет бренда, замените `primaryColor`. Остальные параметры разобраны в [руководстве по теме](../Styles/Theme.mdx), а варианты и размеры кнопок — в [разделе Button](../Components/Button.mdx).

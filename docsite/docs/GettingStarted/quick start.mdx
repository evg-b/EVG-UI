title: Быстрый запуск
description: Как подключить ThemeProvider в React-приложении.
---

После [установки EVG-UI](./Installation.mdx) оберните `<App />` в `ThemeProvider`. Так тема библиотеки будет доступна во всём приложении. В проекте на Vite это можно сделать в `src/main.tsx`.

```tsx title="src/main.tsx"
import { createRoot } from 'react-dom/client'

import { ThemeProvider } from '@evg-b/evg-ui'

import App from './App'

createRoot(document.getElementById('root')!).render(
  <ThemeProvider>
    <App />
  </ThemeProvider>
)
```

Запустите приложение командой `npm run dev` или `yarn dev`. Выбрать компонент и посмотреть, как им пользоваться, можно в [каталоге компонентов](../Components/All.mdx).

## Цвет палитры и цвет темы

`Color` принимает значение цвета или имя оттенка из [палитры](./Palettes.mdx). Чтобы получить цвет кнопки из активной [темы](./Theme.mdx), передайте тему и роль в `getColor`. Оба вызова возвращают объект с методами `Base`, `Contrast` и `Bright`.

```tsx
import { Color, getColor, useTheme } from '@evg-b/evg-ui'

export default function ColorValue() {
  const theme = useTheme()
  const palette = Color('purple700').Base('HEX')
  const primary = getColor(theme, 'primary').Base('HEX')

  return <span>purple700 — {palette}, primary — {primary}</span>
}
```

Оттенки палитры фиксированы. Переключите режим сайта, чтобы увидеть, как меняются роли во втором ряду.

<ColorInfo colors={['pink700', 'purple700', 'blue700']} />
<ColorInfo themed colors={['primary', 'success', 'fail']} />

## Формат и прозрачность

`Base(format, alpha)` возвращает цвет в выбранном формате. Доступны `HEX`, `HEXA`, `RGB`, `RGBA`, `HSL` и `HSLA`. Для форматов с прозрачностью можно указать альфа-канал от 0 до 1.

```ts
import { Color } from '@evg-b/evg-ui'

const purple = Color('purple700')
const hex = purple.Base('HEX')
const overlay = purple.Base('RGBA', 0.2)
```

## Контрастный текст

`Contrast` выбирает чёрный или белый цвет текста по яркости фона. Каждая плашка использует `Color(background).Contrast('HEX')`. Для текста на тематической поверхности можно взять готовую пару токенов, например `theme.primary` и `theme.onPrimary`.

## Яркость

Положительный процент в `Bright` осветляет оттенок, отрицательный — затемняет. Подпись каждой плашки показывает процент изменения.

```ts
import { Color } from '@evg-b/evg-ui'

const orange = Color('orange')
const lighter = orange.Bright('HEX', 20)
const darker = orange.Bright('HEX', -20)
```

## Свойство color {#props-color}

Передайте роль напрямую в `color`. При смене темы кнопка получит новое значение роли, в том числе в состояниях с иконкой и индикатором загрузки.

```tsx
import { Button, Icon } from '@evg-b/evg-ui'

export default function DoneButton() {
  return (
    <Button color="success" variant="contained" startIcon={<Icon name="Check" />}>
      Готово
    </Button>
  )
}
```

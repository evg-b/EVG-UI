## Тень поверхности

`Elevation(level)` возвращает CSS-свойства `boxShadow` и `transition`. Передайте результат в шаблон styled-components. Чем выше целочисленный уровень от 0 до 24, тем заметнее тень.

```ts title="Card.styled.ts"
import styled from 'styled-components'

import { Elevation } from '@evg-b/evg-ui'

export const Card = styled.article`
  ${Elevation(2)}
  padding: 16px;
  border-radius: 8px;
  background-color: ${({ theme }) => theme.surface};
  color: ${({ theme }) => theme.onSurface};

  &:hover {
    ${Elevation(4)}
  }
`
```

## Выбор оттенка

Палитры Material Design экспортируются из EVG-UI по имени и через объект `colors`. Номер оттенка служит ключом. Например, `red[700]` и `colors.red[700]` возвращают `#D32F2F`.

```ts
import { colors, createTheme, generateTokens, red } from '@evg-b/evg-ui'

const tokens = generateTokens({
  primaryColor: colors.purple[700],
  errorColor: red[700]
})
const lightTheme = createTheme({ tokens: tokens.light })
const darkTheme = createTheme({ tokens: tokens.dark })
```

Для элемента, который должен менять цвет вместе с режимом, используйте роль темы, например `theme.primary`. Ниже приведены исходные оттенки и их HEX-значения.

## Подключение темы

`generateTokens` строит два набора токенов из исходных цветов бренда. Выберите `light` или `dark`, передайте этот набор в `createTheme` и оберните приложение в `ThemeProvider` из EVG-UI. Компоненты библиотеки и ваши styled-компоненты получают одну тему.

```tsx title="App.tsx"
import { useState } from 'react'

import { Button, ThemeProvider, createTheme, generateTokens, type ThemeMode } from '@evg-b/evg-ui'

const tokens = generateTokens({ primaryColor: '#7B1FA2' })
const themes = {
  light: createTheme({ tokens: tokens.light }),
  dark: createTheme({ tokens: tokens.dark })
}

export default function App() {
  const [mode, setMode] = useState<ThemeMode>('light')

  return (
    <ThemeProvider theme={themes[mode]}>
      <Button
        color="primary"
        variant="contained"
        onClick={() => setMode(mode === 'light' ? 'dark' : 'light')}>
        {mode === 'light' ? 'Включить тёмную тему' : 'Включить светлую тему'}
      </Button>
    </ThemeProvider>
  )
}
```

## Смена режима и основного цвета

Введите имя в поиск, переключите режим и выберите другой исходный цвет. Фон, кнопки и аватары обновляются, а введённый запрос сохраняется. Переключатели в этом примере действуют только внутри его `ThemeProvider`.

<ThemeChange />

Если пользователь выбирает цвет во время работы, храните `primaryColor` в состоянии и пересчитывайте тему при изменении цвета или режима.

```tsx
const tokens = generateTokens({ primaryColor })
const theme = createTheme({ tokens: tokens[mode] })
```

## Токены в styled-components

Для фона карточки возьмите `surface`, для текста на этом фоне — `onSurface`. Поля объекта `theme` доступны в шаблоне styled-components.

```ts title="Card.styled.ts"
import styled from 'styled-components'

export const Surface = styled.section`
  padding: 16px;
  border: 1px solid ${({ theme }) => theme.outline};
  border-radius: 8px;
  background-color: ${({ theme }) => theme.surface};
  color: ${({ theme }) => theme.onSurface};
  font-family: ${({ theme }) => theme.fontFamily};
`
```

В React-компоненте текущую тему возвращает `useTheme()` из EVG-UI.

```tsx title="Card.tsx"
import { useTheme } from '@evg-b/evg-ui'

import * as Styled from './Card.styled'

export default function Card() {
  const theme = useTheme()
  return <Styled.Surface>Основной цвет — {theme.primary}</Styled.Surface>
}
```

## Свой цвет поверхности и шрифт

У генератора есть пять исходных цветов — `primaryColor`, `secondaryColor`, `successColor`, `warningColor` и `errorColor`. Для точечной настройки возьмите готовый набор нужного режима и замените отдельные токены.

```ts
import { createTheme, generateTokens } from '@evg-b/evg-ui'

const { dark } = generateTokens({ primaryColor: '#7B1FA2' })
const theme = createTheme({
  tokens: { ...dark, surface: '#292D3E', onSurface: '#F5F5F5' },
  fontFamily: 'Arial, sans-serif'
})
```

## Цветовые роли компонентов

Свойство `color` принимает роли темы. Например, `default` использует токен `surface`, `warn` — `warning`, а `fail` — `error`. Здесь показаны значения текущей темы документации.

<ColorInfo themed colors={['default', 'primary', 'secondary', 'warn', 'success', 'fail', 'background', 'surface']} />

О форматах и преобразовании цветов читайте в [разделе Color](./Color.mdx).
